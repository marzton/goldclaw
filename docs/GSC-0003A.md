# GSC-0003A — Cortex Command Surface vertical slice

Local-only implementation in `cortex/`. It connects the browser surface to
the CLAW-HP gateway and installed Codex/Claude Code CLIs without cloning or
copying the selected repository.

## Run

```powershell
npm run cortex:dev
```

Open `http://127.0.0.1:4317`. Run metadata is persisted under
`cortex/data/runs/` and intentionally ignored by Git because it can contain
agent output and local paths.

## Safety boundary

- Device, repository, task, and agent values must exist in `cortex/registry.json`.
- Working directories resolve inside this checkout.
- Context file chips cannot escape the selected repository.
- Codex uses its workspace-write sandbox; Claude Code uses `acceptEdits`.
- Stop targets only the exact spawned process tree.
- No Cloudflare, DNS, IAM, secret, billing, or production deployment path is present.

## Handoff

`Claude Review` creates a new Claude Code run containing the original
task, selected context chips, before/after Git state, and captured Codex
output. The receiving runtime works in the same registered directory.
